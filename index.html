Help

Requirements

macOS 13 Ventura or later.

Reviewing what an agent changed

When another program, such as an AI agent, changes a document you have open, HiMark reloads it and highlights each change. Step through the changes and revert any of them; nothing is saved until you save.

Pointing an agent to your selection

Turn on HiMark → Settings → "Point an agent to selected text". Then ask your agent (Claude Code, for instance) to add HiMark as an MCP server with the command shown under that setting. Select text in HiMark and ask the agent to work on it. The agent sees only your selection in the front document, and its edit shows highlighted and unsaved.

"Allow…" banners

macOS lets HiMark use only the files and folders you choose. When HiMark needs a document's folder, to store a pasted image next to it for instance, it shows a banner with an Allow… button. Choose the folder once and HiMark remembers it.

Language

HiMark follows your Mac's language (English or French). HiMark → Settings → Language picks one; the change applies when HiMark opens next.

Configuration requise

macOS 13 Ventura ou ultérieur.

Relire ce qu’un agent a modifié

Quand un autre programme, un agent IA par exemple, modifie un document ouvert, HiMark le recharge et surligne chaque modification. Parcourez-les et revenez sur celles que vous voulez ; rien n’est enregistré tant que vous n’enregistrez pas.

Partager la sélection avec un agent

Activez HiMark → Réglages → « Partager la sélection avec un agent ». Demandez ensuite à votre agent (Claude Code, par exemple) d’ajouter HiMark comme serveur MCP avec la commande affichée sous ce réglage. Sélectionnez du texte dans HiMark et demandez à l’agent d’y travailler. L’agent ne voit que votre sélection dans le document au premier plan, et sa modification apparaît surlignée, non enregistrée.

Bandeaux « Autoriser… »

macOS ne laisse HiMark utiliser que les fichiers et dossiers que vous choisissez. Quand HiMark a besoin du dossier d’un document, pour y ranger une image collée par exemple, un bandeau propose le bouton « Autoriser… ». Choisissez le dossier une fois : HiMark s’en souvient.

Langue

HiMark suit la langue de votre Mac (français ou anglais). HiMark → Réglages → Langue permet d’en choisir une ; le changement s’applique à la prochaine ouverture.
