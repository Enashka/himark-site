HiMark privacy policy

Last updated: 27 October 2026

Support · Français

HiMark is a Markdown editor for the Mac, made by scienceprod.

HiMark collects no data. It has no account, no analytics, no tracking and no advertising, and it sends nothing about you or your documents anywhere.

  • Your files stay on your Mac. HiMark reads and writes only the files and folders you open with it.
  • Images from the web. If a document you open links to an image on the web, HiMark downloads that image to show it, as a browser would. The site hosting it sees an ordinary request for the image. HiMark sends nothing else.
  • The agent bridge (Settings → "Point an agent to selected text") is off until you turn it on. It works only on your Mac: an AI agent you run yourself, such as Claude Code, can read the text you have selected in HiMark and replace it. HiMark doesn't send that text anywhere; what the agent does with it is up to the agent and its own privacy policy.
  • Settings and your session (open tabs, unsaved text kept in case of a crash) are stored on your Mac, in HiMark's own folder.

Questions: contact@futurproche.ai

Politique de confidentialité

HiMark est un éditeur Markdown pour Mac, créé par scienceprod.

HiMark ne collecte aucune donnée. Pas de compte, pas de mesure d’audience, pas de pistage, pas de publicité : HiMark n’envoie rien vous concernant, ni vous ni vos documents.

  • Vos fichiers restent sur votre Mac. HiMark ne lit et n’écrit que les fichiers et dossiers que vous ouvrez avec lui.
  • Images du Web. Si un document que vous ouvrez contient le lien d’une image sur le Web, HiMark télécharge cette image pour l’afficher, comme un navigateur. Le site qui l’héberge reçoit une simple demande pour l’image. HiMark n’envoie rien d’autre.
  • La passerelle pour agents (Réglages → « Partager la sélection avec un agent ») est désactivée tant que vous ne l’activez pas. Elle fonctionne uniquement sur votre Mac : un agent IA que vous lancez vous-même, comme Claude Code, peut lire le texte sélectionné dans HiMark et le remplacer. HiMark n’envoie ce texte nulle part ; ce que l’agent en fait relève de l’agent et de sa propre politique de confidentialité.
  • Les réglages et votre session (onglets ouverts, texte non enregistré conservé en cas de plantage) sont stockés sur votre Mac, dans le dossier de HiMark.

Questions : contact@futurproche.ai
